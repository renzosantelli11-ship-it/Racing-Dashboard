# 🏎️ Racing Dashboard

A visual and structured web dashboard designed to organize technical information, standings, and telemetry from various motorsport categories (GT3, F1, and WEC).

---

## 🛠️ Built With

* **HTML5:** Semantic page structure.
* **CSS3:** Custom styling built entirely with **Flexbox** for layout and responsiveness.

---

## 📌 Main Features

* **GT3 Section:** Information on the AO Racing team (Porsche 992 "Rexy"), including driver data, track status, and a telemetry panel (tire pressures and electronics).
* **F1 Section:** McLaren section focused on qualifying (Q3 Monaco), featuring Lando Norris and Oscar Piastri data, tire wear per wheel, and ERS configuration.
* **WEC Section:** Ferrari AF Corse (499P) overview at the 24 Hours of Le Mans, covering mechanical specs, fuel strategy, and weather forecasts.
* **Guides & Setups:** Horizontal bottom section containing driving technique guides and category setups.
* **Visual Design:** Dark racing-inspired aesthetic with distinct borders and themed banners for each category.
